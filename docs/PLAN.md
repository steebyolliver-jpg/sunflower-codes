# 向日葵兑换码助手实施计划

用户已于 2026-09-14 确认：iPhone 网页工具、逐条复制、已用勾选与持久保存、筛选、云端每日更新。

## 范围与结构

独立目录，不改动 FDE 教学程序。原生 HTML/CSS/JavaScript 静态页面；Python 标准库采集官方 TapTap 公告；JSON 码库；云端定时配置交付前验证，公开上线配置单独确认。无需 API 密钥或安装运行依赖。

- `dist/`：手机界面、设备本地使用记录、初始码库、离线缓存与主屏幕元数据。
- `scripts/update_codes.py`：读取官方公告、精确大小写去重、提取明确有效期、原子写入码库。
- `tests/`：验证采集边界、失效/部分失败、数据合并、使用状态和复制失败处理。
- `.github/workflows/`：每日采集与 GitHub Pages 发布的可部署配置。
- `README.md` / `VERIFICATION.md`：使用方法、部署条件、实测证据与限制。
