# 向日葵兑换码助手

给 iPhone 使用的轻量网页工具：复制兑换码、自己勾选已用、筛选未使用、读取每日更新的码库。无需游戏账号、登录系统、模型 API 或数据库。

## 手机日常使用

部署成功后，在 Safari 打开实际发布链接，点分享 → 添加到主屏幕。之后固定从同一主屏幕图标进入。

1. 在“未使用”列表点“复制”。
2. 切回微信游戏，在头像的兑换入口粘贴。
3. 成功后回到助手，勾选“已使用”。复制本身不会自动打勾。
4. 需要取消时，在“已使用”列表再次点复选框。

自动复制受限时，页面会提供长按复制窗口。使用记录只保存在当前设备/网站入口；清除网站数据或换设备不保留。初次成功打开后，可离线读取已缓存码库并勾选。

## 本地启动

在本项目目录运行（需要已安装的 Python 3.10+）：

```powershell
python -u -m http.server 0 --bind 127.0.0.1 --directory dist
```

打开终端输出的实际 `http://127.0.0.1:端口/` 地址。该地址仅适用于本电脑；不能把它发给 iPhone 当上线链接。不要直接双击 HTML，因为模块、复制和离线缓存需要 HTTP/HTTPS。

手动更新公开码库：

```powershell
python scripts/update_codes.py
```

## 数据来源与更新规则

- 初始 65 条来自用户于 2026-09-14 提供的历史截图。保留大小写，未逐条验证，不宣称长期有效；原始私人截图不在交付包中。
- 每日检查 [TapTap 官方公告第一页](https://www.taptap.cn/app/732885/topic?type=official) 与 [第二页](https://www.taptap.cn/app/732885/topic?page=2&type=official)，只从明确码段落提取文本。
- [V4INKEJ 官方公告](https://www.taptap.cn/moment/847181583017315115) / [L4XMINF 官方公告](https://www.taptap.cn/moment/839199809716882618)。每条官方码保留独立出处。
- 公告发布渠道不代表微信版通用；真实有效性只能由游戏兑换结果确认。
- 精确大小写去重；历史码不会因滚出公告第一页被删除；个人使用状态不进入码库。
- 明确兑换期限按北京时间判过期；没有明确语境、同一公告多个码对应日期不清等情况保留待核实。
- 任一来源失败，本轮保留全部旧码与旧成功时间，单独记录失败时间和原因；不会把部分检查冒充全部成功。
- 只检查这两个公开列表，无法保证搜遍全网；图片中的码、私域群码和渠道专属码可能遗漏。来源结构改变时需要维护解析器。
- “刷新码库”只读取已发布的 JSON，不会即时触发云端抓取。每日采集不需要手机或个人电脑开机。

## 技术结构

`dist/` 直接作为静态发布目录；所有资源使用相对路径，支持仓库子路径。`dist/data/codes.json` 是共享公开数据，`sunflower.used.v1` 是设备本地使用状态。`sw.js` 缓存界面，不拦截 JSON 更新请求；网络失败由页面读取本地缓存。

Python 采集只用标准库，无第三方运行依赖；更新用同目录临时文件和原子替换，避免半写文件。每日工作流还运行数据逻辑测试；源检查失败时发布保留数据及失败状态，再将任务标为失败，便于维护者发现。
